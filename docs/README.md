Este diretório concentra a documentação técnica e de produto do **BAIRANA**. Novos documentos serão adicionados conforme o projeto gerar decisões reais que precisem ser registradas e mantidas.[^1]

> [!IMPORTANT]
> Os documentos listados abaixo estão **planejados**. Enquanto não forem criados, seus nomes aparecem apenas como código inline e não como links.

## Sobre este diretório

O diretório `docs/` funciona como índice e ponto de entrada da documentação do projeto. Seu objetivo é manter decisões relevantes organizadas sem antecipar arquitetura, políticas ou controles que ainda não foram definidos.

## Documentação planejada

| Documento         | Finalidade                                                                                          | Status    |
| ----------------- | --------------------------------------------------------------------------------------------------- | --------- |
| `architecture.md` | Registrar decisões arquiteturais relevantes e apresentar uma visão geral da arquitetura do BAIRANA. | Planejado |
| `privacy.md`      | Registrar diretrizes de privacidade, minimização e tratamento de dados.                             | Planejado |
| `threat-model.md` | Registrar ameaças, superfícies de ataque, riscos relevantes e considerações de segurança.           | Planejado |

## Princípios de documentação

* **Documentar decisões reais:** registrar o que foi decidido ou implementado, evitando transformar hipóteses em fatos.
* **Evitar duplicação:** manter cada assunto em seu documento apropriado e referenciá-lo quando necessário.
* **Manter o conteúdo atualizado:** revisar documentos quando decisões relevantes mudarem.
* **Proteger informações sensíveis:** não publicar dados reais de moradores, clientes, empreendedores, credenciais ou outros segredos no repositório público.

## Evolução da documentação

Novos arquivos devem ser criados quando houver conteúdo suficiente para justificá-los.

Quando um documento planejado passar a existir, seu nome neste índice poderá ser convertido em um link relativo para facilitar a navegação dentro do repositório.

Até lá, este README deve continuar refletindo apenas o estado real da documentação do BAIRANA.
