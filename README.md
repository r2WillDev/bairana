## Visão geral

O BAIRANA busca tornar mais simples o fluxo de descoberta e contato entre moradores e empreendedores locais.

O objetivo é permitir que moradores encontrem produtos e serviços disponíveis dentro do condomínio e iniciem o contato diretamente com quem oferece a solução.

`Morador` → `BAIRANA` → `pesquisa ou filtra` → `encontra um negócio` → `consulta informações` → `WhatsApp`[^1]

## Escopo atual

O MVP está sendo construído para oferecer uma experiência simples de:

- descobrir produtos e serviços;
- pesquisar e filtrar negócios;
- consultar informações básicas;
- iniciar contato diretamente pelo WhatsApp.
